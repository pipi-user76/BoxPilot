# BoxPilot 安全边界

本文说明 BoxPilot 信任什么、不信任什么，以及每道边界现在做到什么程度、还剩哪些缺口。

## 1. 定位与信任模型

BoxPilot 是单机或内网使用的任务工作台，不是多租户平台。安全模型建立在两点上：

- 宿主机、配置文件和模板代码是可信的。
- 用户提交的网页地址、仓库地址、CSV 内容和仓库里的代码都是不可信的。

因此设计上不追求“把不可信输入变安全”，而是让不可信内容只在沙箱里执行，宿主机只接触结构化结果。

## 2. 输入校验

所有输入统一走 `backend/validation.py`，路由和模板不各自复制规则。

| 输入 | 规则 | 目的 |
|---|---|---|
| 任务 ID | 字母数字开头，最长 64 位，只含字母、数字、下划线和连字符 | 防止目录名注入 |
| 产物文件名 | 只能是单层文件名，不允许分隔符 | 防止写到任务目录外 |
| 相对路径 | 拒绝绝对路径和任何 `..` 片段 | 防止路径逃逸 |
| 网页地址 | 只允许 http、https，不允许 URL 内带账号密码 | 避免凭据进入日志 |
| 仓库地址 | 只允许 https、白名单主机、必须包含 owner 和仓库名、不允许查询参数和片段、不允许凭据 | 限制克隆目标 |
| CSV 文件 | 仅 `.csv`、非空、不超过 5 MB | 控制上传体积和类型 |

## 3. 命令执行边界

- 所有 Shell 调用都经过 `backend/sandbox_client.py`，模板不能直接调用 SDK。
- 命令在 `/home/gem/boxpilot/<task_id>` 下执行，不碰宿主机文件系统。
- 危险模式黑名单拦截提权、删盘、挂载、容器操作、管道下载脚本等命令。
- 单条命令有超时；输出截断到 4000 字符后入库。
- 每个步骤有独立超时（默认 240 秒），整个任务有总时长上限（默认 900 秒）；超时后任务落为 `TIMEOUT`，不会永久停在运行中。
- 黑名单只是第一道门槛，真正的隔离来自沙箱容器，不能把黑名单当成安全保证。

## 4. 仓库体检的额外约束

- 只克隆白名单主机上的公开仓库，浅克隆、单分支、不带标签。
- 禁止交互式登录，避免任务卡在密码提示。
- 克隆失败自动重试一次，每次 60 秒上限；仍失败时给出中文说明和替代方案，并生成 `clone-failure.json` 说明残留产物。
- 只执行预设的 `pytest`、`unittest`、`npm test`，不执行仓库自定义脚本，不递归拉取子模块。
- 依赖安装默认开启；用 uv 在任务目录建独立 `.venv`，只按 `requirements.txt` 或 `pyproject.toml` 声明的依赖安装（Node 为 `npm ci`/`npm install`），再补 pytest 并尝试 `--no-deps -e .`，总时长受 `REPO_INSTALL_TIMEOUT_SECONDS` 限制；安装失败时把输出写入 `install.log` 便于排查。安装和可编辑安装都可能执行依赖包自带的构建脚本，仍需沙箱隔离兜底。默认包源是阿里云镜像，对供应链敏感的场景应把 `UV_INDEX_URL` 设为空字符串改用官方 PyPI。
- 仓库要求的解释器缺失时，会用 `uv python install` 从配置的镜像下载并解压解释器，受 `REPO_PYTHON_INSTALL_TIMEOUT_SECONDS` 限制。镜像默认是 npmmirror；这等于信任第三方分发的 Python 运行时，对供应链敏感的场景应改为官方源或预装进镜像，并把 `UV_PYTHON_INSTALL_MIRROR` 设为空字符串。
- 仓库测试返回非零属于有效检查结果，不视为系统故障。

需要注意：测试命令本身会执行仓库代码，这是仓库体检的固有风险，依赖沙箱隔离兜底。

## 5. 产物边界

- 只有任务目录内、大小大于 0 且不超过 20 MB 的文件才能登记为产物。
- 下载接口只接受已登记的产物 ID，不接受任意路径。
- 内联展示只对图片开放，其余类型强制按附件下载。
- 文本预览按 20 万字符截断，前端用纯文本节点渲染，不解析 HTML，避免预览内容触发脚本。
- 删除任务时同步删除产物目录，避免残留文件被继续访问。

## 6. 网络边界

- 沙箱默认可访问外网，这是网页整理和仓库体检的前提。
- 克隆目标受主机白名单约束，但网页任务目前允许访问任意 http、https 地址，包括内网地址。
- 这意味着网页任务存在服务端请求伪造风险：有人可以借它探测内网服务。当前只建议在本机或可信内网使用。

## 7. 日志边界

- 结构化日志记录任务 ID、类型、步骤、耗时、错误码和错误说明。
- 网页地址和仓库地址会进入日志，属于用户输入，按敏感数据对待。
- 不记录账号密码；URL 校验阶段已拒绝带凭据的地址。
- 日志文件默认保留 3 份、每份 5 MB，需要定期清理或纳入忽略列表。

## 8. 已知缺口与处理顺序

| 风险 | 现状 | 下一步 |
|---|---|---|
| 无认证、无限流 | 只绑定本机回环地址 | 对外提供前增加访问令牌和按 IP 限流 |
| 网页任务可访问内网 | 未限制目标地址 | 增加私网地址开关，默认拒绝回环和私有网段 |
| 黑名单可被绕过 | 依靠字符串匹配 | 改为参数数组执行，减少 Shell 拼接 |
| 仓库测试可执行任意代码 | 在沙箱内运行 | 限制沙箱出网、CPU 和内存，任务结束即回收 |
| CSV 公式注入 | 原样保存上传内容 | 导出到表格软件前转义 `=`、`+`、`-`、`@` 开头字段 |
| 日志未脱敏 | 原样记录地址 | 增加敏感字段过滤和保留天数 |

## 9. 部署建议

- 后端只监听 `127.0.0.1`，通过反向代理对外，并在代理层加认证。
- 沙箱使用独立容器和独立网络，不挂载宿主机目录。
- 限制沙箱出网范围，只放行需要的代码托管和网页域名。
- 定期清理 `artifacts/`、`logs/` 和历史任务记录。
- 演示环境不要放入真实账号、私有仓库地址或业务数据。
