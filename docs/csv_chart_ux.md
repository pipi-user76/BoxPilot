# CSV 图表与产物区改造（m17301）

## 问题

1. 产物区只有约一半屏宽，图表被聊天栏挤到 500px 左右，正文看不清。
2. 图表不能放大，也不能单独下载。
3. 固定配色没有真正落到所有图上，思维导图/热力图仍是旧蓝色。
4. 图表内部字号只有 9–11px，卡片缩小时更小，标签挤在一起。

## 方案

### 0. 渲染架构

- 后端 `backend/csv_analyzer.py` 只产出图表数据（`charts`），不在 Python 里绘制；LLM 只写文字解读。
- 前端 `frontend/task_list.js` 用本地打包的 ECharts 5.5（`frontend/vendor/echarts.min.js`，Apache-2.0）渲染折线、柱状、饼图、热力、散点与思维导图，`renderer: "svg"`。
- 图表容器宽度即 viewBox 宽度，`ResizeObserver` 负责重绘；SVG 导出序列化原 SVG，PNG 导出 3x 画布。

### 1. 产物优先布局

- `body.detail-open` 三栏：`72px` 侧栏 + 自适应任务列表 + 产物区。
- 宽屏 `>1500px`：`72px minmax(300px,1fr) minmax(0,3fr)`，产物区约占 3/4。
- `≤1500px`：`72px 400px minmax(0,1fr)`，保证列表标题仍可辨认；`≤1080px` 回退全宽浮层。
- 列表在产物区打开时只保留任务、状态、操作，隐藏类型/步骤/创建时间三列。
- 顶部栏在宽屏下固定为整页宽度，不参与列表/详情的列宽压缩。

### 2. 图表基准与字号

- SVG 基准宽度统一为 960，随容器等比缩放；不再用 760 固定画布。
- 图内字号提升到 11.5–15：轴刻度 12–13、图例 12.5、节点标题 13–15。
- 折线图 4–5 档 y 轴、最多 7 个 x 标签；柱状/饼图/热力/散点/思维导图重新排布，减少重叠。
- 思维导图根节点 190×56、子节点 260×48，孙节点独立列。

### 3. 统一配色

- 所有图形统一消费 `summary.palette`：
  `#466F87 #78B6C8 #F2D98E #E48578 #98AF1E`
- 折线/散点按系列取色；柱状/饼图按条目轮换；热力图用首色做深浅；思维导图根/子/孙分别取色并加同色描边。
- 缺失 palette 时回退同一组常量，不再出现硬编码蓝色。

### 4. 放大与下载

- 点击任意图表打开 `<dialog class="csv-chart-lightbox">`：
  - 标题：数据集 · 视图；
  - 缩放：− / ＋ / 复位，范围 50%–300%，默认 120%；
  - 下载：SVG（矢量）与 PNG（3x 白底，`imageSmoothingQuality: high`）；
  - 点击遮罩或关闭按钮退出。
- 图表卡右上角提供“下载 SVG / 下载 PNG”，按当前数据集与视图导出。
- 下载文件名：`<任务标题>-<数据集>-<视图>`，自动清理非法字符。

## 验收

- 1764×1000：产物区约 3/4，图表宽约 826px，图内文字可读；列表 400–423px。
- 1280×937：`72px / 400px / 808px`，无横向溢出，图表约 728px。
- 灯箱：120% 默认、缩放按钮、SVG/PNG 下载均可用。

## 滚动与对话（第二轮）

- 打开产物区后，任务列表改为 flex 填充剩余高度：`#task-list { flex:1; min-height:0; max-height:none; overflow-y:auto }`，列表自身滚动，不再依赖外层页面。
- CSV 聊天侧栏固定为 flex 列：消息区 `flex:1; min-height:0; overflow-y:auto`；输入区绝对定位在侧栏底部，消息区预留 46px，长对话只在消息区内滚动。
- 对话改为气泡：助手左侧浅灰、用户右侧蓝底白字，去掉“我/助手”行内标签；旧开场消息在前端压缩为首行摘要。
- 图表字号继续上调：坐标轴 15.5px、标签 15px、图例 15px，`csvText` 默认 14px，并统一 `Segoe UI/Microsoft YaHei` 字体与等宽数字。
- 图表 viewBox 改为跟随容器实际宽度（`Math.max(720, chartBody.clientWidth)`），SVG 1:1 渲染，不再把 960 宽缩到 728–826px；`ResizeObserver` 在侧栏/窗口变化时重绘。
- PNG 使用 3x 画布导出，SVG 用原 viewBox 序列化；两者都保留当前标题与文件名。
