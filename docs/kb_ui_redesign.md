> 对应需求：m14429（工作台对话分框、知识库字号/文档区、空会话、入库按钮联动）、m14505（移除检索滑块）、m14510（知识库删除、选择区重设计）。

## 2. 信息架构

```
知识库页
├─ kb-header：知识库选择器（280–420px / 42px / 15px）+ 文档数备注 + 新建/重命名/删除/刷新
├─ kb-layout
```

- `≤860px`：单列，会话栏限高 190px，选择器 100%。

## 4. 接口

### 新增 `GET /tasks/{task_id}/kb-documents`

```json
[
  {"kb_id": "bb3b...", "kb_name": "竞赛资料", "document_id": "d-1"}
]
```

- 只返回当前 `owner_id` 的库；任务不存在或越权返回 404。
- 用于任务详情按钮状态；每次详情重绘、`kb-ingested`、`kb-changed` 后重查。

### 变更 `GET /kb/{kb_id}/documents`

- 返回 `list[KbDocumentSummary]`，不再下发 `content`。
- 新增 `preview`：去 Markdown 标题、压缩空白、截断 140 字。
- 其余字段：`id/title/url/task_id/kind/chunk_count/created_at/orphaned/artifact_name`。

### 已有 `DELETE /kb/{kb_id}`

- 删除库、文档、问答历史与 Chroma 向量；前端补确认框。
- 确认框展示文档数，红色按钮，不可恢复提示。

## 5. 交互流程

### 入库按钮

1. 详情渲染完成 → 读取当前 `.task-row[aria-current]` 的 `data-task-id`。
2. `GET /tasks/{id}/kb-documents`：
   - 空 → 可点击“添加到知识库”。
   - 非空 → `disabled`，文案“已添加到知识库”，`title` 列出库名。
3. 入库成功 `kb-ingested` 或删除库 `kb-changed` → 重新查询。
4. 切换任务时以 `data-task-id` 判断，避免旧按钮指向旧任务。

### 删除知识库

1. 点击“删除” → 确认框显示名称与文档数。
2. 确认 → `DELETE /kb/{id}`。
3. 成功：重载 `/kb`；有库选第一个，无库进入“还没有知识库”；清空对话与文档；关闭文档栏；广播 `kb-changed`。
4. 失败：保留当前库，提示错误。

### 文档栏

- 点击“文档 N”切换；宽屏推挤布局，窄屏覆盖。
- 文档卡勾选支持批量删除；单卡 × 立即删除。
- 搜索 + 类型筛选在头部常驻。

## 6. 空状态

- 无知识库：图标 + “还没有知识库” + 新建按钮。
- 无会话：“暂无会话 / 提问后会自动保存到这里”。
- 当前会话无消息：图标 + “从一个问题开始” + 三个示例问题 chips + 上传入口。
- 无文档：图标 + 说明 + 上传入口。

## 8. 实施顺序与回滚

1. 后端摘要/任务查询 → 2. 头部与布局 → 3. 文档卡 → 4. 空状态 → 5. 入库按钮 → 6. 删除确认 → 7. 测试与截图。

回滚点：

- 只回滚前端资源版本即可恢复旧界面；接口新增字段向后兼容。
- 删除功能为独立按钮与对话框，移除按钮即禁用删除入口，不影响数据。
